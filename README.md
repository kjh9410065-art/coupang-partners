# coupang-partners

쿠팡파트너스 상품 검색과 Gemini 기반 네이버 블로그 글 생성을 자동화하는 Windows용 Python GUI 프로그램입니다.

## 주요 기능

- 쿠팡파트너스 상품 검색
- 상품 선택 및 대표 이미지 표시
- Gemini AI 블로그 글 생성
- 생성 글 클립보드 복사
- Gemini 서버 503 발생 시 다른 모델로 자동 전환

## 실행 준비

1. Python 3.14 환경에서 의존성을 설치합니다.
2. 프로젝트 폴더에 `.env` 파일을 직접 만듭니다.
3. `.env`에는 쿠팡파트너스 API 키와 Gemini API 키를 입력합니다.
4. `python main.py`로 실행합니다.

`.env`는 API 키 보호를 위해 GitHub에 업로드하지 않습니다.
